# 基于 SpringBoot + Vue  的学校行政办公管理系统

考勤打卡 · 请假审批 · 会议管理 · 财务报销 · 共享文档 · 待办流转 · 留言沟通 · 数据统计

本项目是一套面向学校行政办公场景的数字化协同管理平台，采用前后端分离架构，覆盖**管理员、学校、员工**三类角色。系统围绕"考勤管理、请假审批、会议记录、财务申请与审核、共享文档、待办任务、留言沟通、消息通知、数据统计"等核心业务设计，支持从员工日常办公事务发起，到学校层级审核管理，再到管理员全局监管的全链路数字化运营，构建"流程驱动 + 数据整合 + 协同办公"一体化的校务行政办公平台。

## 核心特性

- **考勤打卡与统计**：员工每日上下班在线打卡，系统自动记录打卡时间、迟到早退情况，生成个人考勤报表与部门考勤汇总，支持按月统计与异常考勤预警。
- **请假审批流程**：员工在线提交请假申请（事假/病假/年假/调休等），填写请假事由、起止时间，流程自动流转至学校层级审核，支持审批通过/驳回/退回修改，审批结果实时通知申请人。
- **会议全流程管理**：支持会议创建、参会人员通知、会议纪要记录与归档，员工可查看参与的会议记录，学校可管理本校会议安排，管理员可全局查看会议数据。
- **财务申请与多级审核**：员工在线提交财务申请（差旅报销/办公采购/活动经费等），填写费用明细与上传票据附件，流程经学校财务审核与支付处理，支持审批进度实时跟踪。
- **共享文档与文件管理**：支持文档分类上传、版本管理、权限控制与全文检索，员工可查看共享文件，学校可管理本校文档库，管理员可全局管理文件资源。
- **待办任务与消息通知**：系统自动生成员工待办事项（待打卡提醒、待审批任务、待处理财务申请等），支持站内消息实时推送，员工可通过消息中心统一处理各类通知。
- **留言沟通与反馈**：员工可发布留言进行工作沟通或问题反馈，学校可查看并回复留言，管理员可管理全校留言记录，形成闭环沟通机制。
- **数据统计与运营看板**：管理员端与学校端均提供数据看板，多维度图表展示。

## 功能模块概览

## 管理员端

管理员为系统最高权限角色，负责全局配置与跨校监管：

### 账号与基础

- **管理员管理**：管理管理员账号，包括账号增删改查、角色分配、权限配置、登录日志查看，支持修改密码与安全设置。
- **学校管理**：管理接入平台的学校信息，包括学校名称、学校编码、地址、联系人、联系电话、账户状态，支持学校账号开通与基础配置。
- **用户管理**：查看全平台所有用户（含各学校员工）信息，包括姓名、工号、所属学校、所属部门、岗位、账户状态，支持用户账号冻结/解冻。
- **岗位管理**：管理全平台岗位字典，包括岗位名称（教师/行政人员/财务人员/部门负责人等）、岗位描述、岗位等级，支持岗位增删改查。

### 办公事务

- **待办任务**：查看全平台待办任务流转情况，包括待审批请假申请、待审核财务申请、待处理留言等，支持全局待办监控与超时预警。
- **考勤记录**：查看全平台员工考勤记录，包括打卡时间、迟到早退情况、缺勤记录，支持按学校/部门/时间筛选与考勤数据统计。
- **会议记录**：查看全平台会议记录，包括会议名称、会议时间、参会人员、会议纪要、所属学校，支持会议记录查询与归档管理。
- **请假申请**：查看全平台请假申请记录，包括申请人、请假类型、起止时间、请假事由、审批状态、所属学校，支持请假数据全局统计。
- **财务申请**：查看全平台财务申请记录，包括申请人、申请类型、申请金额、审批状态、所属学校，支持财务申请全局监控。

### 内容与沟通

- **公告信息**：发布与管理全平台公告，包括公告标题、内容、类型（通知/政策/活动）、发布时间、置顶状态、可见范围（全校/指定学校），支持公告编辑与删除。
- **留言列表**：查看全平台员工留言记录，包括留言内容、留言人、所属学校、留言时间、处理状态，支持管理员回复与留言删除。
- **消息信息**：管理系统消息推送，包括消息标题、内容、接收对象（全平台/指定学校/指定用户）、发送状态，支持批量发送系统通知。
- **用户通知**：查看全平台用户通知发送与阅读情况，包括通知标题、接收人、已读/未读状态、发送时间，支持通知记录查询。

### 资源与数据

- **部门管理**：查看全平台部门组织架构，包括学校-部门-岗位的层级关系，支持部门信息全局查询。
- **共享文档**：管理全平台共享文档库，包括文档名称、分类、上传者、所属学校、上传时间，支持文档审核与违规内容处理。
- **数据统计**：综合数据看板，展示全平台核心运营指标（学校数量/员工总数/今日考勤率/待办处理率/财务支出总额），支持按学校维度对比分析、考勤趋势、请假类型分布、会议频次统计等多维度图表展示，支持报表导出。

## 学校端

学校为独立运营主体，负责本校内部审核与资源管理：

### 账号与基础

- **学校信息**：查看与编辑本校基本信息，包括学校名称、地址、联系人、联系电话、校徽、简介，支持学校资料维护。
- **员工管理**：管理本校员工信息，包括姓名、工号、手机号、所属部门、岗位、入职时间、账户状态，支持员工账号增删改查与密码重置。
- **部门管理**：管理本校部门组织架构，包括部门名称、部门负责人、部门描述、上级部门，支持部门增删改查与层级调整。
- **岗位管理**：管理本校岗位配置，包括岗位名称、岗位描述、所属部门、岗位权限，支持岗位增删改查。

### 办公事务

- **员工待办**：查看本校员工待办任务情况，包括待审批请假、待处理财务申请、待回复留言等，支持待办任务派发与进度跟踪。
- **考勤记录**：查看本校员工考勤记录，包括打卡时间、迟到早退、缺勤情况，支持按部门/时间筛选与考勤月度统计，支持考勤异常处理。
- **会议记录**：管理本校会议记录，包括会议名称、会议时间、会议地点、参会人员、会议纪要、会议状态，支持会议创建、编辑、删除与纪要归档。
- **请假审核**：审核本校员工提交的请假申请，查看请假详情（请假类型、起止时间、事由），支持审批通过/驳回/退回修改，审批结果自动通知申请人。
- **财务审核**：审核本校员工提交的财务申请，查看申请详情（申请类型、费用明细、票据附件、申请金额），支持审核通过/驳回，大额申请可流转至更高层级审批。
- **财务支付**：对已审核通过的财务申请进行支付处理，记录支付时间、支付方式、支付凭证，支持支付状态更新与支付记录查询。

### 内容与沟通

- **文件管理**：管理本校共享文档库，包括文档上传、分类管理、权限设置、版本管理，支持文档搜索与下载，支持文档访问权限控制（部门可见/全员可见）。
- **留言记录**：查看本校员工留言记录，包括留言内容、留言人、留言时间、处理状态，支持学校管理员在线回复与留言标记处理。
- **消息记录**：查看本校消息发送与接收记录，包括系统通知、审批结果通知、待办提醒等，支持消息记录查询。
- **员工通知**：向本校员工发送通知，包括通知标题、内容、接收对象（全体/指定部门/指定员工），支持通知发送与已读状态跟踪。

## 员工端

员工为系统日常使用者，专注个人办公事务办理：

### 账号与个人

- **账户注册登录**：支持工号+密码登录或手机号+验证码登录，首次登录自动关联所属学校与部门，支持找回密码。
- **密码修改**：支持员工自主修改登录密码，保障账户安全。
- **个人信息**：查看与编辑个人基本信息，包括姓名、工号、手机号、所属学校、所属部门、岗位、邮箱，支持查看个人办公档案。

### 办公事务

- **我的考勤**：查看个人考勤记录，包括每日打卡时间、迟到早退情况、月度考勤统计，支持在线打卡（上班打卡/下班打卡），查看考勤异常记录。
- **我的任务**：查看个人待办任务与已办任务，包括待审批事项、待处理工作、任务截止时间、任务状态，支持任务完成标记与任务详情查看。
- **会议记录**：查看本人参与的会议记录，包括会议名称、会议时间、会议地点、会议纪要，支持会议纪要下载与回顾。
- **共享文件**：浏览本校共享文档库，支持按分类搜索文档，查看文档详情与下载，支持文件阅读权限控制。
- **财务申请**：在线提交财务申请，包括选择申请类型（差旅报销/办公采购/活动经费等）、填写费用明细、上传票据附件、填写申请金额与事由，支持查看申请审批进度与历史申请记录。
- **请假申请**：在线提交请假申请，包括选择请假类型（事假/病假/年假/调休等）、填写起止时间、请假事由、上传证明材料（如病假条），支持查看请假审批进度与历史请假记录。

### 沟通与消息

- **留言发布**：向学校发布留言，包括留言内容、留言类型（工作沟通/问题反馈/建议意见），支持查看留言回复记录。
- **员工沟通**：与同事进行工作沟通，支持内部消息发送与沟通记录查看。
- **我的消息**：查看个人收到的所有系统消息，包括考勤提醒、待办提醒、审批结果通知、公告推送等，支持已读/未读管理。
